# Mavic-air-2-training
A nine-module training website for the DJI Mavic Air 2, covering the aircraft, controller, battery, flight modes, sensors, Return to Home, the DJI Fly app, and first flight. Includes diagrams, a checklist, a quiz, and links to the official manual.
# Mavic Air 2 Pilot Training Course

An interactive training website for new DJI Mavic Air 2 pilots, built from the
official DJI user manual (v1.4) and a beginner video guide.
